1. DNS Exfil

DNS Exfiltration — AES-CBC qua DNS queries

Phân tích lưu lượng mạng để khôi phục dữ liệu bị đánh cắp và mã hoá bằng AES, truyền ra ngoài qua DNS queries.

Phân tích

  • Attacker upload shell qua /admin/upload-media.php
  • Tìm được credentials trong error logs: APP_SECRET=F0r3ns1c-2025-CSCV
  • Dữ liệu mã hoá AES-CBC, key/IV sinh từ SHA256 của secret
  • Dữ liệu được chia thành các chunk hex, nhúng vào subdomain của DNS query tới hex.cloudflar3.com

Trích xuất DNS queries

tshark -r 10.10.0.53_ns_capture.pcap -T fields -e dns.qry.name | uniq | grep hex

Script giải mã

import hashlib, re
from Crypto.Cipher import AES
from Crypto.Util.Padding import unpad

app_secret = "F0r3ns1c-2025-CSCV"
h = hashlib.sha256(app_secret.encode()).hexdigest()
key = bytes.fromhex(h[0:32])
iv  = bytes.fromhex(h[32:64])

dns_data, seen = [], set()
with open('dns_exfil.txt', 'r') as f:
    for line in f:
        line = line.strip()
        if not line: continue
        parts = line.split('\t')
        dns_name = parts[-1] if parts else line
        match = re.search(r'^([pf])\.([a-f0-9]+)\.hex\.cloudflar3\.com', dns_name)
        if match:
            prefix, hex_chunk = match.group(1), match.group(2)
            uid = f"{prefix}:{hex_chunk}"
            if uid not in seen:
                seen.add(uid)
                ts = parts[0] if len(parts) > 1 else ''
                dns_data.append((ts, prefix, hex_chunk))

dns_data.sort()
prefix_data = {}
for ts, prefix, chunk in dns_data:
    prefix_data.setdefault(prefix, []).append(chunk)

for prefix in sorted(prefix_data):
    hex_data = ''.join(prefix_data[prefix])
    cipher = AES.new(key, AES.MODE_CBC, iv)
    plaintext = unpad(cipher.decrypt(bytes.fromhex(hex_data)), AES.block_size)
    print(plaintext.decode('utf-8', errors='ignore'))

2. NostalgiaS

NostalgiaS — Malware delivery & .NET Stealer

Điều tra hệ thống người dùng bị xâm nhập để xác định cơ chế phát tán mã độc và đánh cắp dữ liệu.

Chuỗi phân tích

  1. Tìm file ZIP trong Documents (password: secret)
  2. Kiểm tra trình duyệt (Chrome, Edge, IE) qua WebCacheV01.dat
  3. Phát hiện file HTA độc hại: FlashInstaller.hta
  4. Deobfuscate JavaScript → lộ C2 tại 192.168.11.1:3000
  5. Decode payload Base64 từ Pastebin bằng XOR (key: 0x24) → .NET stealer DLL
  6. Tìm registry key HKCU\SOFTWARE\hensh1n → identifier HxrYJgdu
  7. Tìm machine name trong SYSTEM hive → DESKTOP-47ICHL6

Giải mã payload (.NET stealer)

param(
    [string]$InputPath  = ".\90qeYSHA.txt",
    [string]$OutputPath = ".\StealerJanai.dll",
    [byte]$XorKey       = 0x24
)

$raw = Get-Content -Raw -Path $InputPath
$matches = [Regex]::Matches($raw, '0x([0-9A-Fa-f]{1,2})')

$bytes = New-Object System.Collections.Generic.List[byte]
foreach ($m in $matches) {
    $bytes.Add([Convert]::ToByte($m.Groups[1].Value, 16))
}

$out = New-Object byte[] ($bytes.Count)
for ($i = 0; $i -lt $bytes.Count; $i++) {
    $out[$i] = $bytes[$i] -bxor $XorKey
}

[IO.File]::WriteAllBytes($OutputPath, $out)

3. Case AlphaS

Case AlphaS — BitLocker recovery từ ứng dụng ghi chú

Khôi phục dữ liệu từ ổ đĩa VHDX được mã hoá BitLocker bằng cách tìm recovery credentials trong hệ thống.

Chuỗi khai thác

  1. Xác định user directory là windows
  2. Kiểm tra Windows Store app data trong AppData/Packages
  3. SimpleNote: Tìm được password ZIP trong IndexedDB logs:
    5525b8d2d8534b716467493f3660b11e1c44b22cd0c97275619b94a0e5c82fda
  4. ChatGPT: Tìm BitLocker recovery key trong lịch sử hội thoại:
    028853-431640-166364-032076-217943-045837-542388-281017
  5. Mount VHDX bằng recovery key
  6. Giải nén secret.zip bằng password từ SimpleNote
  7. Tìm credentials trong ssh.txt trỏ tới Pastebin

4. CovertS

CovertS — Covert channel qua TCP checksum

Phân tích PCAP để tìm kênh truyền dữ liệu ẩn và khôi phục dữ liệu bị đánh cắp.

Phân tích

  1. Xác định IP nguồn: 192.168.203.91 qua NTP traffic
  2. Phát hiện bất thường: 608 gói TCP đáng ngờ tới 192.168.192.1:3239
  3. Kênh ẩn: Dữ liệu được nhúng trong trường TCP checksum (thay vì payload)

Trích xuất

tshark -r challenge.pcapng \
  -Y "ip.src == 192.168.203.91 && ip.dst == 192.168.192.1 && tcp.dstport == 3239" \
  -T fields -e tcp.checksum > out.txt

Giải mã

import base64

with open('out.txt', 'r') as f:
    lines = f.readlines()

full_hex = ""
for line in lines:
    full_hex += line.strip().replace('0x', '')

raw_bytes = bytes.fromhex(full_hex)
decoded = base64.b64decode(raw_bytes)
print(decoded.decode('utf-8', errors='ignore'))
